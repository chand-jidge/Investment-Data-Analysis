# 📊 Investment Analysis Project

## 📌 Project Overview

This project analyzes an investment survey dataset to identify participant demographics, investment preferences, expected returns, investment duration, and other key patterns.

The project follows an end-to-end data analytics workflow using **Microsoft Excel, MySQL, Power BI, and Python**.

## 🛠️ Tools & Technologies

* **Microsoft Excel** — Data cleaning, PivotTables, descriptive statistics, charts, and analysis
* **MySQL** — Database creation, data querying, aggregation, and business analysis
* **Power BI** — Interactive dashboard, KPI cards, slicers, and data visualization
* **Python** — Exploratory Data Analysis (EDA) using Pandas, NumPy, Matplotlib, and Seaborn

## 🔍 Analysis Performed

### Excel

* Data cleaning and preprocessing
* Descriptive statistics
* PivotTable analysis
* Gender distribution analysis
* Investment preference analysis
* Charts and visualizations
* Correlation analysis

### SQL

* Created database and analytical table
* Imported and analyzed the dataset
* Used `GROUP BY`, `ORDER BY`, aggregate functions, subqueries, and window functions
* Calculated participant percentages
* Analyzed investment preferences, objectives, duration, and expected returns
* Performed data-quality checks

### Power BI

Created an interactive **Investment Analysis Dashboard** containing:

* Total Participants KPI
* Average Age KPI
* Most Preferred Investment KPI
* Top Investment Objective KPI
* Gender Distribution
* Investment Preferences
* Source of Investment Information
* Expected Return Distribution
* Investment Duration
* Interactive slicers for filtering the analysis

### Python

Performed Exploratory Data Analysis using:

* Pandas
* NumPy
* Matplotlib
* Seaborn

Analysis included:

* Dataset exploration
* Data quality checks
* Missing-value analysis
* Duplicate checking
* Descriptive statistics
* Age distribution
* Investment preference analysis
* Objective and duration analysis
* Correlation analysis
* Data visualization

## 📈 Key Insights

* **35 participants** were analyzed.
* **Mutual Funds** were identified as the most preferred investment avenue.
* **Capital Appreciation** was the most common investment objective.
* A significant portion of participants expected returns in the **20%–30% range**.
* **3–5 years** was the most common preferred investment duration.
